# dsh-colorful-commands

[English](README.en.md) | 中文

给 DeepSeek Harness 的界面**按类别上色**：思考、执行命令、危险命令、读写文件、搜索、网络请求、其他工具，以及用户消息与助手回复。另外还能给输入框附近的**界面控件**（权限选择、模型选择等）单独配色。

内置三套预设色板 —— **中国传统色**、**日本传统色**、**马卡龙色系** —— 也可以逐个类别自定义颜色，浅色与深色主题分别设置。

---

## 它做什么

| 类别 | 着色对象 |
|---|---|
| 思考 / 推理 | 推理行（`data-variant="think"`） |
| 执行命令 | `bash` / `pwsh` |
| **危险命令** | 命中危险词表的命令（`rm -rf`、`sudo`、`mkfs`、`DROP TABLE` 等）单独换色 |
| 读取文件 | `read` / `read_image` |
| 写入 / 编辑 | `write` / `edit` / `run_code` |
| 搜索 | `grep` / `glob`（本地搜索） |
| 网络请求 | `web_search` / `web_fetch` |
| 其他工具 | 未分类的工具 |
| 用户消息 / 助手回复 | 消息流里的用户与助手块 |

界面控件：**权限选择**、**模型选择**、**计划模式**、**活动栏**、**工具行控件**。

## 它怎么上色

只加**左侧 2px 竖条 + 表头文字与图标颜色**，不改背景。理由：背景着色会与宿主自己的悬停/选中底色打架，长会话里大面积色块也很吵。

展开后的命令输出、diff、文件内容**不会被染色** —— 颜色只作用于折叠表头，正文保持宿主原生配色。这是刻意的：给大段正文上色会严重伤害可读性。

## 安装

桌面版（DeepSeek Harness Desktop）：**设置 → 插件 → 添加插件**，填包名 `dsh-colorful-commands`，然后重启应用。

Web / CLI profile：

```sh
dsh plugin --profile web add dsh-colorful-commands
```

从源码安装：

```sh
git clone <本仓库>
cd dsh-colorful-commands
dsh plugin --profile desktop add link:.
```

## 在哪里配置

**侧栏「插件」→ 点开「多彩命令」这个组合包 → 配置区就在它的详情页里。**

⚠️ 是**组合包详情页**，不是「设置」页，也不是「内置插件配置」那组（那组只放官方插件）。
本插件注册的是 `plugins.bundle.config`，key = 包名 `dsh-colorful-commands` ——
这是 plugin-manager 内核用于第三方组合包的插槽。

卡片里可以：

- 总开关（关掉立刻恢复原生配色，设置保留）；
- 选预设（中国传统色 / 日本传统色 / 马卡龙 / 不预设）；
- 逐个类别设色：**取色器**、**色号输入**（`#RGB` / `#RRGGBB`）、**色板快选**；
- 浅色与深色主题**分别**设置；
- 看**实时预览** —— 预览走的是与真实渲染同一套样式生成器，所以预览与生效结果不可能不一致。

改动先留在草稿里，点**保存**才写回。

## 权限

**不需要任何特殊权限。** 本插件：

- 不读写任何文件；
- 不发起任何网络请求；
- 不注册 HTTP 路由；
- 不执行、不拦截、不修改任何命令 —— 「危险命令」只是一个颜色判定，判错也只影响颜色。

Host 侧只做一件事：声明设置 schema。全部着色逻辑都在浏览器侧。

## 已知限制

- 着色依赖 DSH 暴露的稳定 `data-*` 属性（`data-tool` / `data-variant` / `data-kind` / `data-chat-flow-kind` / `data-slot`）。DSH 大版本升级若改动这些属性，需要更新 `src/classify.js`（该文件是唯一映射点，且有测试兜底）。
- 不提供圆角、字体、动画等改动 —— 那些属于 DSH 主题本身，不在本插件范围内。
- 危险命令判定是**关键词匹配**，不是命令解析器；它的目的只是视觉提示。

## 开发

```sh
npm run build   # 由 src/ 生成 lib/client.js（含构建期产物守卫）
npm test        # 先 build 再跑全部测试
```

`lib/client.js` 是生成物，**不要手改**。改 `src/` 后必须重建。
