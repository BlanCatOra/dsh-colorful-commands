# 配色自检 demo（复制即用）

把下面整段 prompt 粘进 DSH 发出去，就能**一次点亮所有配色类别**，用来确认插件是否正常工作，
或者截图放到 README / 反馈问题。

> ⚠️ 安全：里面那三条「危险命令」是**故意构造的字符串**，只做 `echo` 打印，
> 不会真的执行任何危险操作。它们的作用是让命令文本里出现 `sudo` / `rm -rf /` 这类
> 危险词，从而触发三档风险色。

---

## 复制这段

````text
帮我做一次「配色自检」。请严格按顺序执行下面 6 步，每一步都必须产生真实的工具调用
（bash / read / grep / edit / web_search / todo_write），不要只在文字里描述、不要跳过、不要合并步骤。

所有操作只在 /tmp/dsh-demo 里进行。结束后不要删除这个目录。

### 第 1 步：建 3 个演示文件（用 bash）
在 /tmp/dsh-demo 下建 a.txt、b.txt、c.txt，每个文件 3 行内容（各文件内容不同）。

### 第 2 步：同一个回合里同时做这三件事（不要分成三步）
1. 读取 /tmp/dsh-demo/a.txt
2. 在 /tmp/dsh-demo 目录里搜索 line
3. 执行 ls -l /tmp/dsh-demo

### 第 3 步：执行三条故意构造的无害命令
⚠️ 下面三条只是把字符串打印出来，不会真的执行任何危险操作，是专门用来测三种风险色的。
请原样照抄执行，不要改写、不要替换、不要加额外参数：

低风险：
echo "低风险示例：普通输出"

中风险：
echo "中风险示例：这里提到 sudo 命令"

高风险：
echo "高风险示例：这里提到 rm -rf / 命令"

### 第 4 步：改写并回读
把 /tmp/dsh-demo/b.txt 的第 2 行改成 line2-edited，然后再读取一次 b.txt。

### 第 5 步：搜一次网页
搜索 "AGENTS.md coding agent convention"。

### 第 6 步：更新计划
把上面 6 步列成一个 todo 列表，全部标记为已完成。

最后用一句话总结这次自检覆盖了哪些类别。
````

> ⚠️ 上面代码块里的 `echo` 命令要**真的用 bash 工具执行**（不是让你复述）。
> 如果你有顾虑，可以把 `rm -rf /` 换成任意危险词（如 `mkfs`、`dd if=`），
> 只要出现在命令文本里就能触发高危色。

## 应该看到什么（中国色预设 · 浅色主题）

| 应出现的类别 | 颜色 | 浅色 | 深色 |
|---|---|---|---|
| 思考 / 推理 | 紫 | `#8A4B9C` | `#B5A0C2` |
| **命令 · 低风险** | 暗红 | `#A7535A` | `#C27C88` |
| **命令 · 中风险** | 正红 | `#C02C38` | `#D47A5E` |
| **命令 · 高风险** | 亮红 | `#DE2A18` | `#F04B22` |
| 读取文件 | 蓝 | `#3170A7` | `#6C9BCA` |
| 写入 / 编辑 | 绿 | `#229453` | `#70C8A4` |
| 搜索 | 青绿 | `#2C9678` | `#57C3C2` |
| 访问 / 搜索网页 | 靛蓝 | `#3C5AAC` | `#7D96D1` |
| **混合活动**（第 2 步那几个活动合并的标题） | 靛蓝 | `#4A4F8C` | `#A8ADE4` |
| 「已完成」 | 墨绿 | `#2F6B4F` | `#7FC49B` |
| 尾部「用量」「分支」 | 石板蓝灰 | `#5A6B7C` | `#8FA3B5` |

> 色值会随预设变化（`japanese` / `macaron` 各不同），但**类别之间必须能区分**。
> 命令三档在国内三套预设下是**固定**的（不随预设变）。

### 重点检查三处

1. **第 3 步的三条命令 = 三种深浅的红** —— 低风险偏暗哑，中风险更正，高风险最亮最浓。
   若三条看起来一样（或出现粉/洋红/橙这类**不同色相**），说明风险分级有问题。
2. **第 2 步那组的标题是靛蓝**（`#4A4F8C`），不是蓝 / 绿 / 红里随便一个 ——
   那表示多个活动被正确识别为"混合活动"。
3. **最后一条消息的尾部：只有「用量」和「分支」是彩色**，复制 / 点赞 / 点踩是灰的。

## 复现过的缺陷（回归用）

这份 demo 就是为下面这些坑设计的，改配色后跑一遍能立刻看出有没有退化：

- 命令三档色相漂移（曾出现"低=藕粉、中=洋红、高=橙红"，已修：`hueWindow` 40 → 20）
- 混合活动标题跟着单一活动变色（曾出现"同一件事因排列顺序不同而变蓝/绿/红"）
- 尾部复制 / 点赞 / 点踩被一起染色
- 「访问 / 搜索网页」蓝色饱和度过高（`#4F84FF` s100 → 已限幅到 s48）
